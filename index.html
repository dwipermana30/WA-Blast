Kelola pendaftar akun

Setujui atau tolak akun yang mendaftar untuk memakai aplikasi ini.

01

Unggah daftar tamu

File Excel (.xlsx / .csv) dengan kolom Nama dan NomorHP di baris pertama. Mengunggah file baru akan menggantikan daftar tamu sebelumnya.

02

Susun kalimat

Gunakan {nama} di mana pun — akan diganti otomatis dengan nama tiap tamu. Tersimpan otomatis ke akunmu.

03

Kirim satu per satu

Setiap tombol membuka WhatsApp dengan nomor dan pesan yang sudah terisi otomatis — kamu tinggal menekan kirim di WhatsApp. Status "sudah terkirim" tersimpan di akunmu, jadi aman walau ganti perangkat.

Belum ada daftar tamu. Unggah file di langkah 1 dulu.
